# Welcome to the AI Development Guidelines!

Hey Space!

Welcome to your **AI Chapter**! 🎉

Here, you'll find everything you need to know about building **clean**, **efficient**, and **maintainable AI systems**. Whether you're working on model training, fine-tuning, or deploying AI solutions, these guidelines will ensure we are all aligned and delivering state-of-the-art results.

Want to contribute? Reach out to Mario De Los Santos to coordinate! You can also check our [roadmap and planning spreadsheet](https://docs.google.com/spreadsheets/d/1yR-4zFoME257_KRC1QrdY8H7lfMt4srXdDhFnhzTelc/edit?usp=sharing) to see what's coming next.

## Why Do We Need This?

Great question! Consistency is key to our success in the AI world. By following these guidelines, we can:

- **Collaborate Smoothly**: Consistent code and processes make it easier to work on each other's AI models and pipelines.  
- **Ensure Model Quality**: Well-structured code and documentation improve reproducibility, debugging, and scalability of AI systems.  
- **Speed Up Onboarding**: New team members can quickly understand and contribute to the codebase, datasets, and models.  
- **Optimize Development**: Cleaner workflows, better testing, and well-documented AI experiments lead to fewer issues and faster iterations.  
- **Enjoy the Process**: Let's face it, building cutting-edge AI systems is more enjoyable when our code and models are clean, organized, and easy to work with!  

Let's work together to innovate, collaborate, and set the standard for AI development 🚀.

## 📚 Chapter Overview

| # | Chapter | Description |

| 1 | Machine Learning Landscape | An overview of the main types of ML (supervised, unsupervised, reinforcement learning) with real-world examples. Introduces core concepts, algorithms, and application domains. |
| 2 | Classification in ML - Introduction | Introduction to classification tasks, from binary to multi-class problems. Includes basic metrics (accuracy, precision, recall) and example use cases like spam detection or image labeling. |
| 3 | Training Models | Covers the training process: data splitting, model fitting, evaluation, and tuning. Introduces key ideas like overfitting, underfitting, cross-validation, and hyperparameter search. |
| 4 | SVM and Decision Tree | Explains how Support Vector Machines and Decision Trees work, with visual examples. Discusses their strengths, weaknesses, and when to choose one over the other. |
| 5 | Unsupervised Learning Methods | Overview of clustering and dimensionality reduction techniques like K-Means, DBSCAN, PCA, and t-SNE. Shows how these are used to uncover hidden patterns in data. |
| 6 | AI with Python - Common algoritms Introduction | Hands-on introduction to popular ML algorithms using Python libraries (Scikit-learn, XGBoost, Keras). Includes code snippets and guided examples with small datasets. |
| 7 | AI with Node - Common algorithms Introduction | Intro to using AI/ML in JavaScript environments, using libraries like TensorFlow.js and Brain.js. Focused on inference and browser-based ML with demos. |
| 8 | Deep Learning - Brief Introduction | Presents the basics of neural networks, layers, activation functions, and architectures like CNNs and RNNs. Helps understand how DL differs from traditional ML. |
| 9 | Generative Image models - Introduction to Services and Models | Intro to image generation using tools like DALL·E, Stable Diffusion, and Midjourney. Includes prompt engineering tips and ethical considerations. |
| 10 | Large Lenguage Models - Introduction and Model selection | Explains how LLMs like GPT, Claude, LLaMA, etc., work and differ. Helps choose the right model based on task: summarization, chatbots, code generation, etc. |
| 11 | GPT Tools - Practical Introduction | Hands-on guide to using GPT-based tools via APIs or platforms like ChatGPT. Covers prompt design and tool usage. |
| 12 | Audio Generation and Processing | Explores audio-based AI including Text-to-Speech (e.g., ElevenLabs), Speech Recognition (e.g., Whisper), and voice cloning. Includes links to samples and tools. |
